## Runtime attachment contract
The canonical machine-readable evidence is `assets/cv/document-qa-manifest.json`.

The dispatcher must, immediately before each send:
1. resolve canonical identity to its assigned QA profile;
2. materialize the exact Library `file_id`;
3. verify file size and SHA-256 against the manifest;
4. base64-encode the verified PDF bytes;
5. attach them through Hostinger Mail API `attachments[]` using `application/pdf` and `base64`;
6. after send, verify the Sent message exists and contains the expected non-zero PDF attachment.

Any materialization failure, hash mismatch, empty attachment or Sent verification mismatch is fail-closed for that identity. No blind resend.
